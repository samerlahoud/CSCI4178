project
=======

Test harness left behind by a previous developer. Nobody documented it.

Layout, as far as anyone can tell:

  src/main/code      the scripts that do the work
  src/main/resources unused
  src/test/code      helpers for the test suite
  src/test/filters   the filters the test suite runs
  src/test/resources unused
  src/it             integration test fixtures
  docs               notes

There is no build system. Everything here is run by hand from a shell.
